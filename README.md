# Project_운동지도 보조RAG

RAG 기반 QA 도구입니다. 공식 지침을 근거로 답하고, 근거 문서와 쪽 번호를 함께 보여주며, 진단·약 조절처럼 의료행위에 해당하는 질문은 의료기관으로 안내합니다.

이 프로젝트의 목표는 챗봇 자체가 아니라 **만들고 → 틀린 것을 찾고 → 고쳐서 → 수치로 증명하는 과정**입니다.

> 이 도구는 운동지도 보조용이며 의료 조언을 제공하지 않습니다.

## 범위

- **질환:** 당뇨, 비만, 고혈압 (+ 일반 성인·노인 기준)
- **하지 않는 것:** 진단, 약 조절 조언, 질환 범위 밖 질문

## 데이터

| 출처 | 문서 | 수집 방식 |
| --- | --- | --- |
| 보건복지부·한국건강증진개발원 | 한국인을 위한 신체활동 지침서, 지역사회 통합건강증진사업 안내(신체활동·비만) | 코드 (robots.txt 금지 게시판은 수동 등록 + 사유 기록) |
| 질병관리청 국가건강정보포털 | 질환별 운동·생활관리 페이지 | 코드 |
| 학회 공개 논문·지침 | 대한당뇨병학회지, 대한비만학회 2020 지침, ADA 2016 성명서 등 | 코드 |
| 규칙 문서 | 보건복지부 비의료 건강관리서비스 가이드라인 | 수동 |

- 목표 문서 수: 60~90개
- 원본 파일은 저작권 보호를 위해 저장소에 올리지 않고, 수집 코드와 데이터코드 표(`data/manifest.csv`)만 공개합니다.

### 사전 점검에서 확인된 문제

| 문제 | 내용 |
| --- | --- |

## 평가

평가셋은 30문항(정답형 20 + 문서에 없는 질문 5 + 함정 5)이며, 문항마다 채점 포인트와 근거 문서·쪽 번호를 붙입니다. 현재 13문항 작성 완료(`eval/questions.csv`).

| 지표 | 뜻 |
| --- | --- |
| 검색 적중률 | 정답 근거가 검색 상위 5개 안에 드는 비율 |
| 채점 포인트 충족률 | 답에 꼭 들어가야 할 내용 중 들어간 비율 |
| 근거 표시 정확도 | 인용한 문서·쪽이 실제 내용과 일치하는 비율 |
| 조건 확인 | 빠진 조건(식사·약·컨디션 등)을 되묻는 비율 |
| 경계 준수 | 진단·약 조절 질문을 의료기관으로 안내한 비율 |

## 빈손 테스트 (RAG 없이 LLM만)

- 설정: gpt-4o-mini, temperature 0, 문항별 독립 호출, 2026-09-28 실행
- 검증: 코드 실행 → AI 보조 1차 채점(원문 PDF 대조) → 사람 전 문항 검토(진행 중)

| 항목 | 1차 결과 (사람 검토 전) |
| --- | --- |
| 설계·당일 판단 채점 포인트 | 23개 중 11.5개 (50%) |
| 함정 문항 통과 | 3개 중 0개 |
| 경계 위반 | 0건 |
| 원문 쪽 내용까지 맞는 인용 | 13개 중 1건 |
| 한국 공식 문서 인용 | 0건 |

RAG로 개선을 보여줄 지점은 근거 정확도, 한국 기준 수치, 함정 문항입니다. 경계 위반율은 이미 0%라 유지 지표로 봅니다.
